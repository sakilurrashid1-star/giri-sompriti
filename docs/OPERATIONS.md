# গিরি সম্প্রীতি: অভ্যন্তরীণ পরিচালনা নির্দেশিকা (Internal Operations)

> **গোপনীয় ও অভ্যন্তরীণ ব্যবহারের জন্য:** এই নির্দেশিকাটি শুধুমাত্র প্ল্যাটফর্ম অ্যাডমিনিস্ট্রেটরদের অভ্যন্তরীণ কাজের সুবিধার্থে সংরক্ষিত।

---

## ১. সাইট ডিপ্লয়মেন্ট ও হালনাগাদের নিয়ম
1. **নিরাপত্তা রুলস আপডেট:** ফায়ারবেস কনসোলে যান (`Firebase Console > Firestore Database > Rules`), `firestore.rules`-এর সর্বশেষ কোডটি পেস্ট করে `Publish` করুন।
2. **কোড পরিবর্তন ও গিট কমিট:** গিট রিপোজিটরির `main` ব্রাঞ্চে পরিবর্তনসমূহ পুশ করুন।
3. **লাইভ রিফ্রেশ:** GitHub Pages সাধারণত ১-২ মিনিটের মধ্যে সাইট বিল্ড সম্পন্ন করে। ব্রাউজারের হার্ড-রিফ্রেশ (`Ctrl + F5`) দিয়ে লাইভ পরিবর্তন যাচাই করুন।

---

## ২. অ্যাডমিন প্যানেল পরিচালনা
- **সম্পাদক প্যানেল:** অ্যাডমিন ড্যাশবোর্ড থেকে অনুমোদিত সম্পাদকদের জিমেইল যুক্ত করুন। তাঁরা পরবর্তীতে Google Login দিয়ে সম্পাদক সুবিধা উপভোগ করবেন।
- **সনদ ব্যবস্থাপনা:** পুরনো কোনো সনদ সিস্টেমে থাকলে "পুরনো সনদ যাচাইয়ের জন্য প্রস্তুত করুন" বোতাম চেপে ডাটাবেস প্রস্তুত করতে পারেন।
- **নিয়মিত ডাটা ব্যাকআপ:** প্রতি মাসে অন্তত একবার অ্যাডমিন ড্যাশবোর্ডের "সব তথ্যের ব্যাকআপ ডাউনলোড (JSON)" বোতাম চেপে ব্যাকআপ কপি অফলাইনে সংরক্ষণ করুন।
