# গিরি সম্প্রীতি: সাইট চালু করার নির্দেশিকা

## ফাইলগুলো
- index.html: পুরো ওয়েবসাইট
- firestore.rules: ডেটাবেসের নিরাপত্তা নিয়ম
- sw.js, manifest.webmanifest, icon-192.png, icon-512.png: ফোনে অ্যাপের মতো ইনস্টল ও অফলাইনে পড়ার জন্য
- logo.png: ফেসবুকে শেয়ারের প্রিভিউ ছবি

## প্রতিবার সাইট হালনাগাদের নিয়ম
1. Firebase > Firestore Database > Rules-এ পুরনো লেখা মুছে firestore.rules-এর পুরোটা পেস্ট করে Publish করুন।
2. GitHub-এর giri-sompriti রিপোতে সব ফাইল (উপরের তালিকার সবগুলো) Add file > Upload files দিয়ে আপলোড করে Commit করুন।
3. ১-২ মিনিট পর সাইট রিফ্রেশ করুন (দরকার হলে ব্রাউজারের কপি মুছে আবার খুলুন)।

## একবার করে নেওয়ার কাজ
- অ্যাডমিন প্যানেল > সনদ ব্যবস্থাপনা > "পুরনো সনদ যাচাইয়ের জন্য প্রস্তুত করুন" বোতাম একবার চাপুন, যাতে আগে দেওয়া সনদগুলো যাচাই পাতায় ধরা পড়ে।
- অ্যাডমিন প্যানেল > সম্পাদক নিয়োগ-এ সম্পাদকদের জিমেইল লিখে সংরক্ষণ করুন। তাঁরা "গুগল দিয়ে অ্যাডমিন/সম্পাদক লগইন" দিয়ে ঢুকবেন।
- নিয়মিত ব্যাকআপ: অ্যাডমিন প্যানেল > ড্যাশবোর্ড > "সব তথ্যের ব্যাকআপ ডাউনলোড" মাসে একবার চেপে ফাইলটি নিরাপদ জায়গায় রাখুন।

## নিরাপত্তা
- অ্যাডমিন যাচাই সার্ভারে (firestore.rules) হয়, ব্রাউজারে নয়।
- দুই অ্যাডমিন গুগল অ্যাকাউন্টে ২-ধাপ যাচাই (2-Step Verification) চালু রাখুন।
